# Архив версий / Version archive

Здесь сохранены все найденные уникальные ZIP-сборки WordPress-плагина, включая ранние GSXR-777 AI Open Chat и WLN Multi-Provider AI Chat. Номера определены по заголовкам PHP-файлов, а не только по именам архивов. Несколько сборок с одинаковым номером версии сохранены отдельно; теги `snapshot` не обозначают отдельные официальные релизы.

Повторяющиеся ZIP с одинаковой SHA-256 сохранены один раз. Их исходные имена перечислены в [manifest.json](manifest.json). Для двух старых архивов удалена только вложенная служебная папка `.git`; контрольные суммы исходного и опубликованного ZIP указаны в манифесте. Локальные конфигурации сервера, тестовые WordPress-сайты и стороннее приложение-донор не относятся к версиям плагина.

This directory preserves all discovered unique WordPress plugin ZIP packages. Versions are read from PHP headers. Multiple snapshots sharing a version remain separate. Byte-identical copies are deduplicated; their names are recorded in the manifest. Embedded `.git` metadata was removed from two old packages without changing plugin source files. Original and published hashes are recorded separately.

## Проверка целостности / Integrity verification

Контрольные суммы опубликованных файлов: [SHA256SUMS](SHA256SUMS). Полный каталог с исходными суммами и сведениями об исключении `.git`: [manifest.json](manifest.json).

PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 .\wln-multi-provider-ai-chat-1.4.8-wordpress-org.zip
```

Linux/macOS (from this directory):

```sh
sha256sum -c SHA256SUMS
```

Для установки выбирайте [последний релиз](https://github.com/gsxr-777/wln-multi-provider-ai-chat/releases/latest). Старые сборки сохранены для истории.
